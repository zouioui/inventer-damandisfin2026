    Paramètres du terminal

    Connexion Wifi / réseau local

    Le bouton LANCER tentera d'envoyer le groupe (rayon, N° ALLE, emplacements) à cette adresse. Cela ne fonctionne que si le terminal est accessible depuis cet appareil (même réseau Wifi) et que son application accepte les requêtes HTTP entrantes. Si l'app installée sur le terminal n'expose pas d'adresse HTTP, laissez ce champ vide : le bouton LANCER affichera quand même la liste des colis, exportable en .txt ou imprimable pour transfert manuel.
